## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Backslash mangling in Bash heredocs | Authoring a Node script via a quoted heredoc silently ate one level of backslashes, so a JS string literal holding a Windows path reached the file with single backslashes. JS then read `\n` as a newline and `\f` as a formfeed, corrupting the path written into STATE.md. Quoting the heredoc delimiter did NOT prevent it. A later heredoc containing quotes and pipes also died with `unexpected EOF`. | advisory | Do not author scripts or docs through Bash heredocs on this project — use the Write tool. Always write Windows paths with forward slashes (`C:/Users/...`); Node, Flutter and git all accept them. After any generated file, verify with `tr -d '\11\12\15\40-\176\200-\377' < file \| wc -c` and confirm it reports 0 stray control characters. |
